# Fellowship demo runbook

Five beats. The console is at `npm run dev` on port 4317. Keys: `1`–`4` load vignettes, space pauses, `L` opens lineage, `M` opens the hypothesis strip, `C` exports awareness CoT.

## Beat 1 — Why a summary lies

Read the first section of the README. The failure mode is a high score on a decoy, a repeated cut from one sensor counted as two sources, or a missing field filled in by a model. TISE rejects the missing field and keeps source grade separate from claim grade.

## Beat 2 — District Seven

Press `1`. Warehouse 7 carries RPK, thermal, and sandbags, so the grid shows a hostile symbol and veracity stays high. The mosque emitter is tagged DECOYING. Building 12 HUMINT is stale against a cold GEOINT pass. Market square keeps the posture at MANEUVER. Point at the ICD 203 sentence: likelihood and confidence are different lines.

## Beat 3 — Quarantine, withdraw, strike gate

Press OUT on the mosque SIGINT row. The delta chip shows the posture move. Press `2` for Corridor Mirage and read WITHDRAW: the overpass is the lure, the rail depot is the gun line. Press `3` for Iron Anvil. Awareness CoT succeeds. Nominate strike. The route returns 403 until a grant is attached. That grant is minted in `mintCommanderApprovalGrant` and is single-use.

## Beat 4 — The code

Open `src/lib/epistemics/subjective-logic.ts`, `src/lib/epistemics/deception.ts`, and `src/lib/synactic/client.ts`. There is no prompt. The Synactic client calls the tools that exist on the-synactic's server card.

## Beat 5 — The proof

```bash
npm test
npm run eval
```

The property tests cover the opinion simplex, secret rejection, echo-chamber fusion, and the civilian strike ban. The scorecard in `docs/EVAL-SCORECARD.md` is the vignette contract.

## If someone asks

- This is a training instrument on a fictional grid. It does not task a real sensor and it does not send a weapon.
- STRIKE means "the evidence would support a nomination," and the policy still wants a person.
- Uncertainty `u` near 1 is an answer. It means the engine does not know, and it will say HOLD.
